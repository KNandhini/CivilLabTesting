# LabProject API

A NestJS-based API for laboratory management system with mobile app support.

## Features

### QR Code Mobile Download Functionality

The system now includes enhanced QR code functionality that automatically triggers PDF downloads when scanned on mobile devices:

#### How it works:

1. **QR Code Generation**: Each PDF page includes a QR code in the bottom-right corner
2. **Mobile-Optimized URLs**: QR codes point to mobile-optimized endpoints
3. **Automatic Download**: When scanned on mobile, the QR code opens an HTML page that automatically triggers the PDF download
4. **Fallback Support**: If automatic download fails, users can manually click the download button

#### Endpoints:

- `GET /reports/mobile/download-page/:requestId` - HTML page with auto-download functionality
- `GET /reports/mobile/test-request-form/:requestId` - Direct PDF download optimized for mobile
- `GET /reports/test-request-form-by-request` - Standard PDF download with mobile support

#### Mobile Optimizations:

- Mobile user agent detection
- Optimized HTTP headers for mobile browsers
- Cache control headers to prevent download issues
- Automatic download triggers with fallback options
- Responsive HTML interface for better user experience

#### Usage:

1. Generate a test request form PDF
2. QR codes are automatically added to each page
3. Scan QR code with mobile device
4. PDF automatically downloads or opens download page
5. Users can manually download if automatic download fails
